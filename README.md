# Order Summary Component

A clean and reusable order summary card built with HTML and CSS. This project demonstrates a simple e-commerce checkout-style UI component.

## ✨ Features
- Reusable order summary layout
- Responsive pricing card design
- Clear product and total information
- Modern UI styling
- Easy to customize for any project

## 🛠️ Technologies Used
- HTML5
- CSS3
- Responsive Design

## 🚀 Live Demo
https://ahmed62001.github.io/order-summary-component/

## 📖 How to Use
1. Clone the repository:
   ```bash
   git clone https://github.com/ahmed62001/order-summary-component.git
   ```
2. Open `index.html` in your browser.
3. Customize the text, prices, and styling as needed.
